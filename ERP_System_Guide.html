System Architecture — Multi-Company
Ek hi system mein multiple companies kaam kar sakti hain

🏗️ Kaise structured hai?

SA
Super Admin (Platform Owner)

Poore system ka malik. Nayi companies register/block kar sakta hai. Plan manage karta hai.

C1
Company 1 — Alpha Manufacturing

Apna alag data, apne users, apna stock. Dusri company ka data nahi dekh sakta.

C2
Company 2 — Beta Traders

Bilkul alag account. Same system, completely isolated data.

🔗 Tech Stack

Frontend

React 18, Tailwind CSS, React Query, Zustand

Backend

Node.js, Express, PostgreSQL (Supabase), JWT Auth

Cloud Services

Cloudinary (images), Socket.IO (real-time), Nodemailer (email)

Dispatch Management

Maal bhejna — LR, E-way bill, delivery tracking

Dispatch Kaise Banayein?
Customer ke liye maal ready hai → dispatch banao → track karo
1
Sidebar → "Dispatch" → "+ New Dispatch"

2
Customer aur delivery address select karo

Customer master se auto-fill hoga

3
Items add karo

Kya bhejna hai, kitna quantity, rate

4
Transport details dalo

Vehicle number, LR number, transporter name, driver phone

5
E-way bill number dalo

GST portal se generate karke yahan paste karo

6
Status update karte raho

Ready → Packed → Dispatched → Delivered

🚦 Dispatch Status Flow

Ready — Maal taiyar hai, bheja nahi
Packed — Packing ho gayi, vehicle ready
Dispatched — Truck nikal gaya
In Transit — Raste mein hai
Delivered ✅ — Customer ko pahunch gaya
💡
Dispatch se Invoice Link karo

Invoice banate waqt dispatch ID select karne ka option milega — automatically items fill ho jaayenge.

Invoice & Billing

GST Invoice banana, payment track karna, PDF download karna

Invoice Kaise Banayein?
GST calculate automatic hoga — CGST+SGST (intra-state) ya IGST (inter-state)
1
Sidebar → "Invoices" → "Create Invoice"

Ya list pe "+ Create Invoice" click karo

2
Customer select karo

Customer master se — address auto-fill hoga

3
Inter-state ya Intra-state?

Toggle se select karo — GST automatically split ho jaayega

4
Items add karo

Material, Qty, Rate, HSN Code, GST% — total calculate hoga

5
"Create Invoice" karo

Invoice number auto generate hoga (INV-000001 format)

6
PDF download karo ya payment add karo

Detail page mein dono options hain

💰 GST Calculation

🏠 Intra-State (Same State)

Taxable Amount₹10,000
CGST (9%)+ ₹900
SGST (9%)+ ₹900
Total₹11,800

✈️ Inter-State (Different State)

Taxable Amount₹10,000
IGST (18%)+ ₹1,800
Total₹11,800
✅
Payment Record Karna

Invoice detail page mein "Add Payment" click karo → amount, mode (Cash/Bank/UPI/Cheque), reference number dalo → Balance automatically update hoga.

Common Problems & Solutions
Koi problem aaye toh ye check karo pehle
❌ Login nahi ho rahaEmail aur password dobara check karo. Password case-sensitive hai. Caps Lock on toh nahi hai?
❌ GRN banaya par stock nahi badhaQC Status "Rejected" toh stock nahi badh'ta. "Approved" ya "Conditional" select karo aur accepted quantity check karo.
❌ Material dropdown mein nahiPehle material banao (Materials → Add Material). GRN ya Production mein tab dikhega.
❌ Invoice PDF mein logo nahiSettings mein company name, logo aur GST number set karo pehle.
❌ "Users" menu nahi dikh rahaYe sirf Company Admin aur Super Admin ko dikhta hai. Apna role check karo.
❌ Production order start nahiPehle Workflow Template banana padega (Production → Workflow Builder). Bina workflow ke order create nahi hota.
❌ Backend start nahi ho rahabackend folder mein jao → npm install → phir npm run dev. Database SQL pehle run karo.
❌ Frontend blank aa raha haifrontend folder mein npm install → npm run dev. Backend bhi chalu hai? http://localhost:5000/health check karo.
